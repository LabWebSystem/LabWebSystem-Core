# Lab-Core Dashboard (MVP)

## 実装済み範囲
- 日本語 UI
- React-Grid-Layout ベースの監視ウィジェットダッシュボード
- 固定トピックに縛られない可変ページの監視ページ切り替え
- ウィジェットのドラッグ移動、リサイズ、追加、削除
- ウィジェットごとのデフォルトサイズ / 最小サイズ制約
- ウィジェットサイズに応じた compact / standard / detail 表示切り替え
- 追加前にプレビュー UI と `n×m` サイズを確認できるウィジェット追加モーダル
- レイアウトの DB 保存 / 復元
- CPU / メモリ / ディスク / ネットワーク / アラート / ログ / グラフ / ステータス表示
- アプリ登録フォーム
- 登録テスト値入力（OruCa想定 / シンプルWeb / Headless API）
- アプリ一覧（状態・更新有無）
- 再起動・再ビルド・更新確認・更新適用・ロールバック
- アプリログビューア（サービス切替・表示行数切替・自動スクロール）
- 削除確認フロー（削除モード選択 + 確認名入力）
- DNS/Proxy 手動同期ボタン
- 最近のイベント表示

## UI変更時の参照先
- ダッシュボードの見た目ルールは `docs/readmes/ダッシュボードUIデザインルール.md` を参照する
- UI を追加・修正するときは、既存画面の骨格よりもこのルール文書を優先して整合性を確認する

## 開発
1. `yarn install`
2. `yarn workspace @lab-core/dashboard dev`
