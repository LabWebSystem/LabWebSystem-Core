# BUG-005: deploy が未タグの検証済みHEADで不可読なGitエラーを返す

Status: VERIFIED
Area: developer workflow / deploy
Symptom: `mise run deploy` がHEADにrelease tagがない場合、`git describe --tags --exact-match HEAD` の内部エラーをそのまま表示して終了した。新規releaseの標準入口として、タグ作成やRelease workflow起動まで到達できなかった。
Cause: deploy taskが既存の `v0.1.0` tagを前提とし、tag作成、originとの整合性確認、pushを実装していなかった。
Fix: clean working treeを確認し、`VERSION`から決めたrelease tagがHEADにない場合はローカルで作成する。originに同じtagがなければpushしてRelease workflowを起動し、既存tagが別revisionを指す場合は停止する。
Verification: `yarn tsc -p tsconfig.scripts.json`; `memadr check`; `memadr index`
FutureRelevance: reusable
Decision: deploy taskはRelease tagの準備とCI Release workflowの開始を標準入口として担当する。
ResolvedBy: CHG-013
Related: ADR-007; ADR-006; CHG-012; CHG-013
CurrentValue: current
ValidityScope: `mise run deploy` のrelease tag準備とworkflow起動
