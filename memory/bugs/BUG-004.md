# BUG-004: Production Compose の Backend readiness 用ディレクトリが未設定

Status: VERIFIED
Area: production compose / backend readiness
Symptom: Core Release 0.8.1をlwsctlから新規インストールするとBackendは起動するが、`/health/ready`が503になり、Backendのhealthcheck待ちでDashboardが起動しない。
Cause: Production Composeが`LAB_CORE_DATA_DIRECTORY`だけを永続領域へ設定し、`appsRoot`、`appDataRoot`、`generatedSyncDir`、DBパスをイメージ内の未作成または非永続パスのままにしていた。
Fix: 4つのreadiness対象とDBを`/var/lib/labwebsystem`配下へ設定し、`LWS_DATA_DIR`配下のサブディレクトリを個別にbind mountする。
Verification: `docker compose config`で環境変数とbind mountを確認し、一時Dockerコンテナで同じ親子bind mount構成のディレクトリが読み書き可能になることを確認する。
FutureRelevance: reusable
CurrentValue: current
ValidityScope: Core production Compose / Release 0.8.1+
ResolvedBy: CHG-011
Related: ADR-006; CHG-010
