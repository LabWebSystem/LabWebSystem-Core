# BUG-002: Production Backend imageにDocker CLIが含まれない

Status: VERIFIED
Area: production image / Docker runtime
Symptom: Backend containerへDocker socketを渡しても、production runtime imageにDocker CLIとCompose pluginがなく、resource inspectionやapplication compose操作を実行できない。
Cause: Dockerfileのruntime stageがNode.jsとアプリ成果物だけをコピーし、Docker Engine clientをインストールしていなかった。
Fix: Docker公式Debian repositoryから`docker-ce-cli`と`docker-compose-plugin`をruntime imageへインストールする。
Verification: Backend image build時のruntime package installationを確認し、image内のDocker CLI/Compose実行を検証する。
FutureRelevance: watch
CurrentValue: current
ValidityScope: Production Backend OCI image
ResolvedBy: CHG-009
Related: ADR-004; CHG-007; CHG-009
