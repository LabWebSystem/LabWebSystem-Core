# BUG-001: Production Backend imageからOpenAPI定義が欠落する

Status: VERIFIED
Area: production image / backend startup
Symptom: Production Backend imageを起動すると、`openapi.ts`が`/app/core/backend/openapi/openapi.yaml`を見つけられず、Backend processが終了してreadinessがunhealthyになる。
Cause: Multi-stage Dockerfileのruntime stageがTypeScriptのdistと依存packageだけをコピーし、runtimeから参照する静的な`core/backend/openapi/openapi.yaml`をコピーしていなかった。
Fix: runtime stageで`/build/core/backend/openapi`を`/app/core/backend/openapi`へコピーするようにした。
Verification: Backend OCI imageをbuildし、container内の`/app/core/backend/openapi/openapi.yaml`の存在を確認する。
FutureRelevance: watch
CurrentValue: current
ValidityScope: Production Backend OCI image
ResolvedBy: CHG-008
Related: ADR-004; CHG-007; CHG-008
