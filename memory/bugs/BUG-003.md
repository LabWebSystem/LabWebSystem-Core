# BUG-003: Release workflowのchecksum検証がrunnerで失敗する

Status: VERIFIED
Area: release-automation
Symptom: GitHub Actionsの`Prepare Release assets`がawk構文エラーで終了し、GitHub Releaseが作成されなかった。
Reason: GitHub Actionsのshell scriptに`awk '{print \\$1}'`を記述していたため、runner上でawkの構文エラーになりRelease asset準備が停止した。
Fix: `awk '{print $1}'`へ修正し、shell scriptとしてrunner上で評価される文字列にした。
FilesChanged: .github/workflows/core-release.yml; memory/bugs/BUG-003.md
Verification: GitHub Actions再実行でrelease asset準備とGitHub Release作成を確認する。
Related: CHG-009; ADR-005
CurrentValue: current
ValidityScope: Core GitHub Actions release workflow
