# CHG-015: Production の公開を Core 管理 Caddy proxy に集約

Status: ACTIVE
Reason: dashboard が host の `0.0.0.0:80` へ直接公開され、生成済み DNS / Caddy routing が Production runtime に適用されていなかった。
Change: Production Compose に Caddy proxy と TLS 永続 volume を追加し、host port 80 / 443 の公開を proxy だけへ移した。Backend は dashboard/API を含む Caddyfile を生成し、登録 Application の upstream network を proxy に接続して Caddy を reload する。System test は `dashboard.lab.localhost` 経由の到達と未知 Host の 404 を検証する構成へ変更した。
FilesChanged: infra/compose/compose.yaml; core/backend/src/services/infrastructure-sync.ts; core/backend/src/lib/env.ts; infra/compose/system-test.yaml; scripts/tasks/system-test.ts; infra/production/runtime.env.example; infra/proxy/Caddyfile.system-test; README.md; docs/readmes/Lab-Core運用手順書.md; docs/readmes/LabWebSystem Coreデプロイ仕様書.md; docs/readmes/LabWebSystem外部契約.md; docs/readmes/LabWebSystem Core 開発・検証・デプロイ体制仕様書.md
