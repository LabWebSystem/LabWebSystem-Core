# CHG-002: system 起動時の backend/dashboard 直公開を廃止

Status: ACTIVE
Reason: `yarn system:up` で起動した `backend` と `dashboard` が `127.0.0.1:7300` / `127.0.0.1:5173` に直接公開され、reverse proxy のドメイン導線を経由しなくてもアクセスできていた。
Change: `infra/compose/docker-compose.dev.yml` から `backend` / `dashboard` の `ports` 公開を削除し、`proxy` と共有する Docker ネットワーク `labcore-kernel` を追加した。ローカル開発用 Caddy 生成設定は `host.docker.internal` ではなく `backend:7300` / `dashboard:4173` を逆引きするよう更新し、起動スクリプトで共有ネットワークを自動作成するようにした。
FilesChanged: infra/compose/docker-compose.dev.yml; infra/compose/docker-compose.proxy.yml; scripts/dev/root-command.ts; core/backend/src/services/infrastructure-sync.ts; core/backend/openapi/openapi.yaml; core/backend/.env.example; core/backend/README.md; README.md; docs/readmes/Lab-Core運用手順書.md; memory/changes/CHG-002.md
Verification: `docker compose -f infra/compose/docker-compose.dev.yml config`; `docker compose -f infra/compose/docker-compose.proxy.yml config`; `corepack yarn workspace @lab-core/backend build`; `corepack yarn quality:typecheck:scripts`
Related: CHG-001
CurrentValue: current
ValidityScope: `yarn system:up` で起動する Lab-Core 開発用 backend/dashboard/proxy の到達経路
