# CHG-003: Operation 基盤と jobs→operations migration の土台を追加

Status: ACTIVE
Reason: 仕様変更書で `Operation` を正式な実行単位とし、旧 `jobs` テーブルと `/api/jobs`・旧操作 API を置き換えることが求められた。
Change: backend に Operation 型、Repository、Service、Route の基盤を追加した。SQLite schema を再構成し、`applications.deleted_at` / `deployments.released_at` / `routes.released_at` を含む新制約へ移行したうえで、既存 `jobs` を `operations` へ冪等移行する migration を実装した。Operation の create/cancel/retry/startup interrupt と log 取得仕様を先にテストで固定した。
