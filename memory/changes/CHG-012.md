# CHG-012: mise task 中心の開発・検証・デプロイ体制へ移行

Status: ACTIVE
Reason: profile 選択と repository-wide Yarn command が開発の前提となり、日常開発と本番相当検証が同じ状態へ結合していた。
Change: `mise.toml` に目的別 task を追加し、Vite HMR / backend watch の local development、Docker image の container verification、DNS / proxy を含む isolated system verification、Release tag の deploy 入口を実装した。旧 launcher、config wizard、system Compose、profile 操作、repository-wide Yarn scripts を削除した。製品バージョンを VERSION と `0.1.0` に統一した。
FilesChanged: mise.toml; package.json; core/backend/package.json; core/backend/src/lib/env.ts; scripts/tasks/*; infra/compose/system-test.yaml; infra/proxy/Caddyfile.system-test; infra/dns/Corefile.system-test; VERSION; README.md; docs/readmes/LabWebSystem Core 開発・検証・デプロイ体制仕様書.md
Verification: `yarn install`; `yarn tsc -p tsconfig.scripts.json`; `mise run test`; `mise run test:container`; `mise run test:system`
Related: ADR-007; SUP-002
CurrentValue: current
FutureRelevance: reusable
