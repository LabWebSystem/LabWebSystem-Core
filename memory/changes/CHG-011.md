# CHG-011: Production Compose の Backend 永続パスを readiness 契約へ統一

Status: ACTIVE
Reason: Production Backendのreadinessが要求するディレクトリがCompose起動時に存在せず、Core Release 0.8.1のDashboardが起動できない。
Change: `LAB_CORE_DB_PATH`、`LAB_CORE_APPS_ROOT`、`LAB_CORE_APPDATA_ROOT`、`LAB_CORE_SYNC_DIR`と生成ファイルのパスを`/var/lib/labwebsystem`配下へ設定した。`database`、`apps`、`appdata`、`generated`を`LWS_DATA_DIR`配下から個別にbind mountし、初回起動時にもreadiness対象を作成する。
FilesChanged: infra/compose/compose.yaml; docs/readmes/LabWebSystem Coreデプロイ仕様書.md; docs/readmes/LabWebSystem外部契約.md
Verification: `docker compose config`; 一時Dockerコンテナによる親子bind mountの読み書き確認; `git diff --check`
Related: ADR-006; CHG-010; BUG-004
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Core production deployment / GitHub Release / lwsctl integration
