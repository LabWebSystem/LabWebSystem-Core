# CHG-007: lwsctl向けProduction外部契約と配布基盤を追加

Status: ACTIVE
Reason: lwsctlがBackend API・内部DB・Core repositoryへ依存せずLabWebSystem全体を管理できるP0基盤が未整備だった。
Change: sdk-contractへCore config、Release manifest、Recovery descriptor、Docker labelsのschemaを追加した。BackendにProduction config.yaml読込、version/installation ID、`/health/live`・`/health/ready`、Application recovery descriptorの生成・削除、managed Docker labelsを追加した。Backend/DashboardのProduction Dockerfile、Nginx/Caddy設定、Production Compose、config/runtime/releaseサンプルを追加した。
FilesChanged: sdk/packages/sdk-contract/src/core-contract.ts; sdk/packages/sdk-contract/tests/core-contract.test.ts; core/backend/package.json; core/backend/src/lib/env.ts; core/backend/src/index.ts; core/backend/src/services/application-paths.ts; core/backend/src/modules/operations/application-runtime.ts; core/backend/src/modules/operations/operation-runner.ts; core/backend/src/services/compose-sandbox.ts; infra/compose/Dockerfile.backend; infra/compose/Dockerfile.dashboard; infra/compose/nginx.dashboard.conf; infra/compose/Caddyfile.production; infra/compose/compose.production.yml; infra/production/*; docs/readmes/LabWebSystem外部契約.md
Verification: `corepack yarn install`; `corepack yarn workspace @lab-core/sdk-contract build`; `corepack yarn workspace @lab-core/sdk-contract test`; `corepack yarn workspace @lab-core/backend build`; `corepack yarn workspace @lab-core/backend test`; `corepack yarn workspace @lab-core/dashboard build`; `corepack yarn quality:typecheck:scripts`。Docker Engineが環境にないためProduction Composeの`docker compose config`と実コンテナ起動は未検証。
