# CHG-004: Application 正規API・Operation Runner・OpenAPI/README・dashboard API client を同期更新

Status: ACTIVE
Reason: Operation 基盤だけでは frontend / OpenAPI / README が旧 Job API を参照し続け、リポジトリ内の正が分裂するため。
Change: backend の正規 Application API に `PATCH /api/applications/{id}`、`GET /api/applications/{id}/deployment`、`GET /deployment/inspection`、`GET /runtime-logs` を追加した。Operation Runner を実装し、dry-run / execute の両モードで Step・Log・状態遷移を進めるようにした。さらに `index.ts` を新 Router/Runner/Operation startup 処理へ配線し、dashboard の API client を Operation API ベースへ張り替えた。OpenAPI、backend README、root README、API Trace Map も新仕様へ更新した。
