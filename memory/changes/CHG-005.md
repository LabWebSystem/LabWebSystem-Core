# CHG-005: destroy コマンドを soft / hard に分離

Status: SUPERSEDED
Reason: 従来の `yarn destroy` が container / network / volume / DB / runtime data / backup を一括で削除し、`--yes` と `--force` で確認や安全制御を回避できたため、削除範囲と安全性が不明瞭だった。
Change: ルート scripts と `scripts/maintenance/reset-lab-core.ts` を更新し、`yarn destroy:soft` と `yarn destroy:hard` を追加した。`destroy` は後方互換で soft 相当へ寄せ、preview・mode 別装飾・`yes` 完全一致の対話 confirmation を必須化した。あわせて `--yes` / `--force` を廃止し、soft は container / network / generated artifact のみ、hard はそこへ DB / volume / backup / runtime data 削除を追加する構成へ整理した。
