# CHG-010: Coreデプロイを最小Compose Releaseへ移行

Status: ACTIVE
Reason: Coreをlwsctl非依存でDocker Composeだけから導入・更新・再生成できるようにする。
Change: Production Composeを`compose.yaml`へ統一し、backend/dashboard image、network、永続data bind mount、restart、依存関係、healthcheckをそこで定義した。host configをruntime.envの4項目へ集約し、config.yaml、Caddyfile、cache volume、旧root manifestを削除した。tag-only workflowは両multi-arch imageを公開後、最小release.jsonとcompose.yamlをGitHub Releaseへ新規作成する。
