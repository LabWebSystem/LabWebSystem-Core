# CHG-014: deploy に明示versionとRelease再作成フローを追加

Status: ACTIVE
Reason: deploy taskのversionが固定値で、未作成tagからのRelease開始と既存Releaseの再デプロイを扱えなかった。
Change: `mise run deploy --version vX.Y.Z` の引数解析、git/gh/auth確認、clean working tree確認、既存tag / Releaseの削除確認、tag作成・pushを実装した。Release workflowのversion検証を動的なvX.Y.Z形式へ変更し、関連ドキュメントを更新した。
