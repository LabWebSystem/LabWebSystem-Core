# CHG-009: Release manifestとmulti-arch公開workflowを追加

Status: SUPERSEDED
Reason: lwsctlの正式Release検査には、公開GitHub Release、version一致したGHCR image、release.json、Compose、Caddyfileが必要だった。またBackend runtime imageにはDocker操作用clientが必要だった。
Change: rootへ正式`release.json`を追加し、Compose checksum・version・platform・image・migration情報を固定した。Backend runtimeへDocker CLI/Compose pluginを追加した。`v<semver>` tagからlinux/amd64・linux/arm64 imageをGHCRへpushし、匿名pull可能なpublic packageへ設定したうえで、release.json、compose.production.yml、Caddyfile.productionをGitHub Releaseへ公開するworkflowと、既存タグを対象に再実行できる`workflow_dispatch`、不要なbuild contextを除外する`.dockerignore`を追加した。既存Releaseのassetを上書きして再実行できる。
FilesChanged: release.json; .dockerignore; infra/compose/Dockerfile.backend; .github/workflows/core-release.yml; memory/decisions/ADR-005.md; memory/bugs/BUG-002.md; memory/changes/CHG-009.md
Verification: Core contract checker `--skip-published-release`; release/config schema validation; Backend build; Dockerfile/runtime image verification; GitHub Actions workflow syntax validation。GitHub Release公開後に通常モードのCTL検査を実行する。
Related: ADR-004; ADR-005; ADR-006; BUG-002; SUP-001; CHG-010
