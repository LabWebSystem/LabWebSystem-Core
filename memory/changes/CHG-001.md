# CHG-001: セットアッププロファイルと system コマンドを統一

Status: ACTIVE
Reason: `config:set` のプロファイル選択と `environment:dev/lab:*` の起動コマンド選択が二重化し、`vm` と `custom` が現在仕様として不要になっていた。
Change: 設定プロファイルを `mock` / `local` / `lab` に整理し、正規コマンドを `yarn system:up/down/logs` に統一した。`environment:dev:*` と `environment:lab:*` は非推奨エイリアスへ変更した。`core/backend/.env` に `LAB_CORE_PROFILE` / `LAB_CORE_PROXY_HTTP_BIND` / `LAB_CORE_DNS_BIND` を出力し、Compose へ明示的に渡すようにした。さらに `config:set` で検出した IPv4 候補から Main/SSH 用 IP を対話選択できるようにした。
