# ADR-005: Core Releaseはタグ起点のGitHub Actionsでimageとartifactを同時公開する

Status: SUPERSEDED
Context: lwsctlはGitHub Releaseの公開状態、release.json、Production Compose、補助Caddyfile、公開imageの対応を正式Releaseの成立条件として検査する。手動アップロードではmanifestとimage tag、Compose checksumの不一致を防ぎにくい。
Decision: `v<semver>` tagを起点にGitHub Actionsでlinux/amd64・linux/arm64のBackend/Dashboard imageをGHCRへpushし、同じtagからrelease.json、compose.production.yml、Caddyfile.productionをRelease assetとして公開する。manifestのCompose checksumをworkflowで再計算して一致を検証する。
Rejected: ローカルから単一architecture imageを手動pushし、Release assetを個別アップロードする方式は、再現性と対応platformの保証が弱いため採用しない。
Consequence: GitHub Actionsにcontents:writeとpackages:write権限が必要で、GHCR packageは匿名pull可能な公開設定にする必要がある。Release tag、manifest version、image tagは同一versionでなければならない。
