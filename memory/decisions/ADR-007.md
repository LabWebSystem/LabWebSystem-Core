# ADR-007: 開発者向け操作を目的中心の mise task に統一する

Status: ACCEPTED
Context: 旧構成は `config:set` による profile 選択と、profile に対応した repository-wide Yarn command を必要とし、UI / backend の日常開発にも Docker、proxy、DNS の状態が影響していた。Local Development、Container Verification、System Verification、Deploy の保証範囲も混在していた。
Decision: リポジトリ全体の公開操作を `mise run dev`、`dashboard`、`backend`、`test`、`test:container`、`test:system`、`deploy`、`stop`、`clean` に限定する。タスク自身が目的に必要な設定と一時環境を決定し、開発は Vite / watch、container と system は独立した Docker 検証とする。`mock` / `local` / `lab`、`config:*`、`system:*`、`service:*`、`quality:*` は公開概念として廃止する。
Rejected: profile 選択を残したまま alias だけを追加する案は、目的中心の操作体系と状態非依存の要件を満たさないため採用しない。すべての検証を単一の開発 Compose へ統合する案は、日常のフィードバック速度と本番相当検証の独立性を損なうため採用しない。
Consequence: 旧 repository-wide Yarn command と profile 用実装は後方互換なしで削除する。Docker 検証は開発より重いが、実行時の独立性と再現性を得る。Production Release の外部契約は ADR-006 のまま維持する。
Related: CHG-012; SUP-002; ADR-006
CurrentValue: current
ValidityScope: LabWebSystem Core の開発・テスト・検証・デプロイ操作体系
