# ADR-004: lwsctlとの接点を外部契約へ限定する

Status: ACCEPTED
Context: LabWebSystem全体の導入・停止・起動・更新・復旧をBackend APIやBackend内部DBへ依存させると、Backend停止・DB破損時にCTLが動作できない。ProductionではCore repositoryやホストNode/Yarn/Gitも前提にしない必要がある。
Decision: lwsctlとCoreの共有契約をRelease manifest、Production Compose、Docker labels、`/etc/labwebsystem/config.yaml`、readiness、Application recovery descriptorへ限定する。インストール済みversionはrelease manifest、Application復旧情報は`apps/<application-id>/state.json`を正本とし、Backend内部schemaは公開契約にしない。
Rejected: lwsctl専用のBackend管理API、Backend DBの直接参照、開発repositoryのProduction bind mountは、Backend停止時の管理不能と実行環境依存を残すため採用しない。
Consequence: CoreのRelease artifactにOCI image、Production Compose、config/release schema、migration情報を含める必要がある。Application runtimeは外部復旧に必要なdescriptorとDocker labelsを更新し続ける。
Related: ADR-003; CHG-007
CurrentValue: current
ValidityScope: Production lifecycle management / lwsctl integration / release artifact
