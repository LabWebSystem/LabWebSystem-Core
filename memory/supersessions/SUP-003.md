# SUP-003: deployの自動tag準備を明示version指定方式で置換する

Status: ACTIVE
Supersedes: CHG-013
Reason: VERSION固定値から暗黙にtagを決める方式では、Release versionが操作面から分からず、既存Releaseの再作成手順も統一されていなかった。
NewBaseline: ADR-008; CHG-014
CurrentValue: current
FutureRelevance: reusable
ValidityScope: Core Release deployment task
ReactivatedIf: 旧deploy実装の移行履歴を調査する場合のみ参照する。
Related: ADR-008; CHG-014
