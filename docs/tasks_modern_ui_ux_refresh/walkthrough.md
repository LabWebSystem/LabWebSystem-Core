# 修正内容の確認

## 1. UI/UX 改善の要点

- `scripts/tasks/interactive-tasks.ts` を `@inquirer/prompts` 主体の実装へ更新。
- 画面上部にクイックアクションを追加:
  - 検索して実行
  - すべて展開
  - すべて折りたたむ
- ツリー表示は維持しつつ、グループ選択で開閉できる構成にした。
- 各コマンドに説明（実行コマンド文字列）を表示し、実行前に確認できるようにした。

## 2. 既存ライブラリ活用

- `select`: メインの階層ブラウズ UI
- `search`: コマンド名/実行内容の検索 UI
- `confirm`: 連続実行の確認 UI

## 3. 体験面の改善

- 単純な縦リストから「ブラウズ + 検索」の2導線へ拡張。
- 一覧が長くても検索で即実行可能。
- 展開状態を保ったまま繰り返し操作できる。

## 4. 検証

- `yarn run typecheck:scripts` 成功。
- `yarn run tasks` の TTY 起動で、以下を確認:
  - 階層表示
  - グループ開閉
  - 検索メニュー表示
