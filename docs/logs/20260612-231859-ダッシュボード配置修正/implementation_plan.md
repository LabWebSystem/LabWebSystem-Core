# 実装計画

## 方針

ダッシュボードの不具合は、個別 UI よりもレイアウト保存データの整合性崩れが根本要因になっていたため、配置判定とレイアウト修復を共通化して対処する。

## 実施項目

1. `core/dashboard/src/dashboard/layout.ts` に、ウィジェットサイズ制約の補正、安全配置探索、ダッシュボード全体の再配置処理を追加する
2. `core/dashboard/src/hooks/useDashboardWorkspace.ts` で、保存前レイアウト修復、ページ跨ぎ移動時の安全配置、全削除操作を扱えるようにする
3. `core/dashboard/src/views/HomeView.tsx` で、初回修復、編集モード遷移時の修復、全ウィジェット削除ボタン、ドラッグ中のページ送り連携を追加する
4. `yarn --cwd core/dashboard vite build --outDir dist-codex-check` でビルド確認する

## 想定効果

- リサイズ後に別サイズへ戻る問題を抑止する
- グリッド外やページ外へ保存されるレイアウトを自動補正する
- 次ページ自動配置やページ跨ぎドラッグの安全性を上げる
- 壊れたレイアウトを編集モード突入時に自己回復させやすくする
