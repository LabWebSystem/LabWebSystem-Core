# タスクリスト

## 依頼内容
- 既存のSDK構成案に、開発/本番の安全な切り分けを満たす設計を追記する。
- 前提:
  - Lab-Core は DB 等を提供しない純粋なコンテナ配信プラットフォーム
  - アプリ単体で起動・検証可能な設計を推奨
  - 専用デバイス依存アプリは仮想デバイスやテストデータ導入で検証可能にする

1. 既存 SDK 調査レポートの見直し
2. 開発/本番分離のSDK要件を設計
3. CLI・プロファイル・CI・ガード設計を追記
4. 実装優先度を更新

## 完了条件
