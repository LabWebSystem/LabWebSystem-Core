# 実装計画

## 方針

ダッシュボードのページ配置は、現在編集中のブレークポイントを基準に厳密に守る。非表示ブレークポイントの都合で desktop 配置を阻害しないようにしつつ、アクティブな画面幅では必ず安全なグリッド内に収まるようにする。

## 実施項目

1. ガードレールの配置判定と修復処理へ「厳密判定に使うブレークポイント」を渡せるようにする
2. ウィジェット追加・ページ跨ぎ移動・ドラッグ終了・リサイズ後修復で、現在のブレークポイントを基準に再配置する
3. ドラッグ中のウィジェット位置には実カードの代わりにプレースホルダを表示し、ページ移動中でも配置先が視認できるようにする
4. TypeScript / Vite build と配置関数の計算確認で回帰を検証する

## 期待効果

- desktop で空きがあるのに 3 個目以降が次ページへ送られる挙動を解消できる
- ページ移動ドラッグ時に、移動先ページでも配置先が見え、実際に配置できるようになる
- リサイズ後のガードレールが過剰に別ブレークポイントへ引っ張られず、現在画面での操作性が安定する
