# 修正内容の確認

## 概要

ダッシュボードの表示幅とスクロールを調整し、ジョブパネルを単一キュー表示に変更した。あわせて、バックエンド起動時に古い未完了ジョブを中断扱いへ整理するようにした。

## 変更点

### 1. 余白とスクロール

- ヘッダーとメイン領域の左右余白を縮小した
- 最大幅制限を外し、横方向の利用可能領域を広げた
- `body` を `overflow: auto` に変更した
- メイン表示領域を `overflow-auto` にして、縦長コンテンツの見切れを防いだ

### 2. ジョブパネルの整理

- `失敗ジョブ` / `実行中・待機中` / `最近のジョブ` の分離をやめた
- 単一の `ジョブキュー` リストへ統一した
- 長いメッセージは折り返しつつ 4 行で要約し、カードの高さ差を抑えた
- ジョブ状態はバッジで表現し、カード自体の構造は等価に揃えた
- 完了済みジョブは `削除` できるようにした

### 3. 未完了ジョブの整理

- バックエンド起動時に `queued` / `running` のジョブを検出する
- `queued` は `cancelled`、`running` は `failed` へ更新する
- これにより、前回プロセス由来の「謎の実行中ジョブ」が残りにくくなった

## 確認結果

- `corepack yarn workspace @lab-core/backend build` : 成功
- `corepack yarn workspace @lab-core/dashboard build` : 成功

## 補足

- 実行中ジョブの本当の強制停止は未実装で、今回の対象は「再起動後に残る見かけ上の未完了ジョブ整理」と「完了済みジョブの削除」まで
- 既存の root 所有 `dist` 残骸は今回もビルド時に退避して回避した
