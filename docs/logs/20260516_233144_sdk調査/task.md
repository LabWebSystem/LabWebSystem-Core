# タスクリスト

## 依頼内容
- Lab-Core に適合するアプリ作成が難しいため、SDK化を見据えて以下を調査する。
  1. アプリ作成に最低限必要なもの・ルール
  2. 理想的なSDK構成

## 実施タスク
1. 現行仕様ドキュメントの確認（正式仕様・既存ガイド）
2. バックエンド実装の確認（登録API、compose解析、ジョブ実行）
3. ダッシュボード実装の確認（登録ウィザード入力項目・補助ロジック）
4. 必須ルールと難易度要因の整理
5. SDKの理想構成案（契約・ツール・配布・CI）を作成

## 完了条件
- 現行実装に基づく必須要件が列挙されている
- SDKの理想構成が実装可能な粒度で提案されている
- 調査結果が `walkthrough.md` に報告としてまとまっている
