# 実装計画

1. 添付デザインの要点を整理する
   - インディゴ / スレート基調
   - カード型レイアウト
   - ステップ進行の視認性向上
   - ロック状態の明示
2. 現行ダッシュボードの UI 構成を確認する
   - `DashboardShell`
   - `ImportView`
   - `ComposeInspectDialog`
   - 既存 CSS の詳細画面向けクラス
3. 追加画面を新デザインへ置き換える
   - URL 解析
   - ブランチ確認
   - manifest 確認
   - compose 解析
   - 登録フォーム
4. compose 検査ダイアログを同系統のデザインへ更新する
5. シェルと詳細画面系の既存スタイルを再調整してダッシュボード全体の統一感を出す
6. ビルドで動作確認し、差分をコミットする
