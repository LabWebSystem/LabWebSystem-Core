# 修正内容の確認

## 概要

現在のダッシュボードデザインを将来の UI 変更でも維持できるように、見た目ルールを正式文書として固定化した。さらに `AGENTS.md` と README 導線に組み込むことで、UI 変更時に参照漏れしにくい構成へ変更している。

## 主な変更

- `docs/readmes/ダッシュボードUIデザインルール.md`
  - ダッシュボードの色、レイアウト、カード、テーブル、ボタン、入力欄、余白、アイコンのルールを整理
  - 新規 UI を追加するときの判断基準と実装前チェックリストを追加
- `AGENTS.md`
  - ダッシュボード UI を触る前にルール文書を必読とする運用ルールを追加
- `docs/readmes/説明書一覧.md`
  - 現行説明書一覧に UI ルール文書を追加
- `core/dashboard/README.md`
  - ダッシュボード実装時の参照先として UI ルール文書を明記

## 効果

- UI の印象が実装者ごとにぶれにくくなる
- 新しい画面やコンポーネント追加時に、どこへ合わせるべきかが明文化される
- 将来ルールを更新するときの更新先が一箇所に定まる
