# タスクリスト

## 依頼内容

- ダッシュボードのヘッダーにある「ジョブパネルを開く」ボタンの左へ「VS Codeで開く」ボタンを追加する。
- ボタンのアイコンは VS Code のものを使う。
- SSH 接続先 IP は固定値にせず、環境ごとに動的な値を使う。

## 対応方針

- `system.execution.sshServiceIp` を利用して VS Code Remote-SSH 用 URL を生成する。
- ボタンは既存ヘッダーの標準ボタンスタイルへ合わせる。
- 接続先が取得できない場合は、無効化したボタンを表示する。
- ブランドアイコン例外を UI ルールへ追記する。
