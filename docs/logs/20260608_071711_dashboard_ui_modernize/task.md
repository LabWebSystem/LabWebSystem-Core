# タスク

- ダッシュボード UI を、添付ドキュメントに沿ってモダンな SPA 風レイアウトへ更新する
- デザイン面はドキュメント準拠としつつ、既存の機能・操作導線・データ表示の整合性は維持する
- 主要対象は `DashboardShell.tsx`、`HomeView.tsx`、`ApplicationsView.tsx`、`styles.css`

## 参照ドキュメント

以下を今回の UI 改修の基準として扱う。

```md
# 🎨 UI/UXのモダン化のご提案

ダッシュボードのデザインを、より洗練されたモダンなSPA（Single Page Application）のUI/UXにアップデートしました。過度なグラデーションや複雑な装飾を廃止し、Tailwind CSSのユーティリティクラスを最大限に活用して、清潔感と視認性の高いフラットデザインを採用しています。

* **レイアウトの刷新**: ヘッダーとサイドバーを用いた標準的なSaaSライクなレイアウトに変更し、ナビゲーションを直感的にしました。
* **配色のシンプル化**: 背景をクリーンな**slate-50**に統一し、コンテンツ領域を明確に区切ることで情報のメリハリをつけています。
* **カードデザインの改善**: 丸みを抑えた**rounded-xl**を採用し、控えめなシャドウとボーダーを組み合わせることで、モダンな印象を与えます。
* **カスタムCSSの削減**: **styles.css**に依存していた複雑な独自クラスを大幅に削除し、メンテナンス性を向上させました。

以下に変更を加えたファイルの全文を提示します。
```
