# 実装計画

1. 添付ドキュメントの意図を読み取り、既存のダッシュボード実装との差分を整理する
2. `DashboardShell.tsx` を SaaS ライクなヘッダー + サイドバー + コンテンツ構成へ変更する
3. `HomeView.tsx` をフラットなメトリクスカードと注意領域中心のホームへ再構成する
4. `ApplicationsView.tsx` を情報整理型カード一覧へ再構成する
5. `styles.css` は背景色・トースト周辺をドキュメントの方向へ寄せつつ、詳細画面や追加画面が依存する既存クラスは壊さない範囲で温存する
6. `corepack yarn workspace @lab-core/dashboard build` でビルド確認する

## 実装方針メモ

- 添付ドキュメントのコードはそのまま転写せず、既存の型・データ構造・ジョブ導線に合わせて調整する
- 既存機能への影響を最小化するため、今回の主変更対象は shell / home / applications の 3 画面を中心とする
- `styles.css` の全面削除は詳細画面と追加画面の既存スタイル依存が大きいため避ける
