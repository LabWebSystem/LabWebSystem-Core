# 実装計画

## 方針

表示不具合そのものの前に、ブラウザが読んでいる配信物が最新コードから生成されているかを確認する。配信物が古い場合は、ビルド失敗要因と権限問題を解消したうえで、実配信サービスまで更新する。

## 実施項目

1. `src` と `dist` に `全ウィジェット削除` の文言が存在するか確認する
2. `core/dashboard/dist` の所有権・更新時刻を確認し、古い配信物が残っているか調べる
3. 正式な `yarn --cwd core/dashboard build` を通し、失敗原因があれば修正する
4. `dashboard` コンテナの配信内容を `curl` で確認する
5. 調査結果をログとして保存する
