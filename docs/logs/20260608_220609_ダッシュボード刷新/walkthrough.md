# 修正内容の確認

## 概要

添付の参考デザインに合わせて、ダッシュボード全体の骨格を刷新した。既存の機能導線は維持しつつ、シェル、ホーム画面、アプリ一覧、ジョブパネルを同じトーンで再設計している。

## 主な変更

- `core/dashboard/src/components/DashboardShell.tsx`
  - 細いサイドバーとミニマルヘッダーを持つ新シェルへ変更
  - ビューごとの見出し、システム状態、ジョブ件数を上部に集約
  - 背景グラデーションと大型コンテンツパネルで全体の印象を刷新
- `core/dashboard/src/views/HomeView.tsx`
  - 運用概要のヒーローセクションを追加
  - メトリクス、インフラ状態、注意アプリ、ジョブ、イベントを再配置
  - システム状態を視覚的に把握しやすいカード構成へ再整理
- `core/dashboard/src/views/ApplicationsView.tsx`
  - 一覧ヘッダーにサマリーカードを追加
  - 各アプリカードを新トーンへ調整
  - 詳細遷移や外部リンクなどの操作導線は維持
- `core/dashboard/src/components/JobsPanel.tsx`
  - 右スライドパネルの見た目を刷新
  - 待機 / 実行中 / 失敗の集計を上部カード化
  - 各ジョブの状態と操作ボタンを整理
- `core/dashboard/src/App.tsx`
  - 新シェルで必要なシステム情報と選択アプリ名を受け渡すように変更

## 機能維持

- アプリ詳細画面への遷移は維持
- ジョブパネルの開閉、再実行、取消、削除は維持
- 手動更新と設定同期ボタンは維持
- 既存の詳細画面、追加画面との接続は維持
