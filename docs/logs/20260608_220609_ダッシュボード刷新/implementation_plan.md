# 実装計画

1. 参考デザインの要点を整理する
   - 細いサイドバー
   - ミニマルヘッダー
   - 情報密度の高いカードレイアウト
   - 状態を色とチップで即時判別できる構成
2. 既存ダッシュボードの責務を確認する
   - `DashboardShell`
   - `HomeView`
   - `ApplicationsView`
   - `JobsPanel`
3. シェルレイアウトを刷新する
   - 背景の雰囲気
   - ナビゲーションの骨格
   - ヘッダーの情報設計
4. ホーム画面を再構成する
   - 概要ヒーロー
   - メトリクスカード
   - インフラ情報
   - 注意アプリ、ジョブ、イベントの再配置
5. アプリ一覧とジョブパネルを新トーンへ寄せる
6. `corepack yarn workspace @lab-core/dashboard build` で確認し、コミットする
