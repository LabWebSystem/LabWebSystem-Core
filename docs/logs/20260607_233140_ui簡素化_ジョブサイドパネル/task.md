# タスク

ダッシュボード UI をさらに簡素化し、文字量を減らし、アイコンを増やし、ジョブ一覧をヘッダー起点のサイドパネルで確認できるようにする。

## 依頼内容

UIについて。
文字情報が多い。
アイコンが少ない。
「今どこに注意すべきかを、最初の一画面で把握できます。
登録済みアプリ、実行中ジョブ、直近イベントをまとめて確認しながら、詰まりや失敗をすぐ追える構成に更新しました。」みたいなポエムがマジで必要ない。
CSSで全てなんとかしようとするんじゃなくて、react-iconsやtailwind、shadcn-uiなどのスタイルライブラリを活用して。

あと、ジョブ一覧はサイドパネルで確認できるようにしたい。パネル開閉ボタンはヘッダーに置いて。
