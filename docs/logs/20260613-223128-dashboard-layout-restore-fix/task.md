# タスク

## 件名

ダッシュボードでウィジェットの存在は保存されるが、サイズ・位置・表示状態が再読み込み後に保持されない問題を修正する。

## 背景

- 保存 API 呼び出し自体は成功している。
- しかし保存済みの `x / y / w / h` が再読み込み後に崩れる。
- コンソールには `Unable to preventDefault inside passive event listener invocation.` も出ている。

## 完了条件

- レイアウト初期化時に高さ 1 行へ潰れた状態で保存されない。
- 保存済みレイアウトが通常表示時に不要な再整形で上書きされない。
- `wheel` 操作での `passive event listener` 警告を解消する。
