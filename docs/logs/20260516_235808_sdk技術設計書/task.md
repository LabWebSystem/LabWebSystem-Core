# タスクリスト

## 依頼内容
- Lab-Core 向け SDK の技術的な設計書を作成する。
- 設計書には以下を含める。
  1. 必要な機能
  2. SDK に使用する言語・フレームワーク
  3. 具体的なディレクトリ/ファイル構成
  4. 使用方法（ユースケース）
  5. SDK の保守方法（core 修正時の追従方法）

## 実施タスク
1. 既存実装（登録API、compose解析、ジョブ実行、ログ取得）に整合するSDK要件へ分解
2. SDKの責務を package 単位に分割
3. コマンド仕様とユースケースを定義
4. core 変更時の互換性維持プロセスを定義
5. 技術設計書を `sdk_technical_design.md` として作成

## 完了条件
- 設計書単体で PoC 実装に着手できる
- core 変更時の保守フローが明記されている
- 開発/本番分離（dev-sim/prod ガード）が設計に組み込まれている
