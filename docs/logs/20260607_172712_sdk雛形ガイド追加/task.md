# タスク整理: SDK雛形ガイド追加

## 依頼内容
- SDK で雛形を作成する際、`labcore` ディレクトリ配下に SDK の使い方ドキュメントも一緒に作成する。

## 目的
- 雛形生成直後の利用者が、どのファイルを編集し、どのコマンドを順に実行すればよいかをローカルで即座に確認できるようにする。

## 完了条件
1. `labcore init` 実行時に `labcore/SDK使い方.md` が生成される。
2. 生成ドキュメントに初回編集ポイントと主要 CLI コマンドが載っている。
3. 自動テストで生成物を検証できる。
4. 関連する現行ドキュメントへ生成物の説明を反映する。
