# 実装計画

1. 既存のセクション/項目編集ループを廃止し、直線的な入力フローへ置換する。
2. ウィザードで扱う項目を以下の3つに限定する。
   - `LAB_CORE_MAIN_SERVICE_IP`
   - `LAB_CORE_SSH_SERVICE_IP`
   - `LAB_CORE_ROOT_DOMAIN`
3. その他の設定値はプロファイル (`local/lab/vm/custom`) の既定値を適用する。
4. 最終プレビューで「3項目 + 既定値適用」を明示し、保存確認後に `.env` を生成する。
5. 補足メッセージで「詳細設定は `.env` を後から編集可能」と案内する。
6. `node --check` で構文検証する。
