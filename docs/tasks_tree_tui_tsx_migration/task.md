# タスク

`yarn run tasks` の TUI を単純な1列リストではなく、`:` 区切りを階層として扱う開閉可能リストへ変更する。

あわせて、`scripts` 配下の `.mjs` をすべて `.ts` に置き換え、実行系を `tsx` ベースへ移行する。

## 完了条件

- `yarn run tasks` で階層グルーピング表示になる。
- グループを開閉できる。
- 既存コマンドは維持されたまま選択実行できる。
- リポジトリ内の `scripts` 配下に `.mjs` が残らない。
- `package.json` の scripts は `tsx` で `.ts` を実行する。
