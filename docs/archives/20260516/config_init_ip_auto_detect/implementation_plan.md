# 実装計画

1. `scripts/config/env-wizard.mjs` にマシンのネットワークインターフェース取得処理を追加する。
2. 外向き IPv4 候補を抽出し、重複排除・優先度付けして提示する。
3. 候補が複数ある場合は選択プロンプトを表示する。
4. 選択IPを `LAB_CORE_MAIN_SERVICE_IP` / `LAB_CORE_SSH_SERVICE_IP` に設定してよいか確認ダイアログを表示する。
5. 承認時のみ値を反映し、拒否時は既定値を維持してウィザードを継続する。
6. 既存の IP 入力バリデーションを厳密な IPv4 判定に統一する。
7. `node --check` で構文検証する。
