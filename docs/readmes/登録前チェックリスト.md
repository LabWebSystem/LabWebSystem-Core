# 登録前チェックリスト

対象読者:
- LabWebSystem にアプリを登録する開発者

文書ステータス:
- current

最終更新日:
- 2026-06-07

## 1. 必須チェック
1. フロントエンドが same-origin の `/api` を使っている
2. 配備用 `docker-compose.yml` に `ports:` がない
3. `web` service が manifest の `exposure.service` と一致している
4. `web` service が manifest の `exposure.port` で listen している
5. 永続データが `APPDATA_ROOT` 経由でコンテナ外へ出ている
6. `yarn labcore:lint` が通る
7. `yarn labcore:preflight` が通る
8. `yarn labcore:guard` が通る
9. export 結果の `hostname` が配備先ドメインに合っている

## 2. 追加で見ると安心な点
- `prod` profile に `docker-compose.dev.yml` が混ざっていない
- `prod` profile に `LABCORE_DEVICE_MODE=real` がある
- `localhost` 固定 URL が env や compose に残っていない
- README に公開サービス名、公開ポート、永続データ保存先が書かれている
